# Private Beta Feature Matrix

| Capability | Initial state | Gate |
|---|---|---|
| Telegram CRM, drafts, signals, packages | Enabled | Owner allowlist |
| Calendar confirmation and MCP status | Enabled | Explicit command |
| LinkedIn OAuth status and disabled preview | Enabled | Minimal scopes |
| Scheduled briefings | Conditional | Verified recipient and schedule |
| Public HTTP sources | Conditional | Source review and HTTPS |
| Image generation | Conditional | Provider and storage review |
| Assisted prospect discovery | Conditional | Human candidate approval |
| Real LinkedIn publishing | Disabled | Separate package-specific approval |
| Scraping, messaging, connection requests, reactions | Always disabled | No supported path |
