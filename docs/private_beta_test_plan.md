# Private Beta Test Plan

**Owner-only:** run health/readiness, system integrity, backups, OAuth
persistence, Calendar read-only status, disabled publishing preview, CRM,
signals, packages, manual outreach, and feedback.

**Trusted users:** add one numeric ID at a time; repeat authorization,
latency, privacy, failure recovery, and command clarity checks.

**Controlled writes:** a real LinkedIn text or image post is a separate
explicit test only after a frozen package is reviewed. No real Calendar event
is created as part of deployment certification.

Record workflow success/failure, duration, backup result, and uncertainty
counts without storing message content or sensitive personal attributes.
